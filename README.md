# Gheras Social Comment Router

نظام موحّد لإدارة تعليقات **غراس العلم للعلم الشرعي** على:

- Facebook
- Instagram
- Telegram

المشروع يعيد بناء مستودع `facebook-reply-bot` ليصبح المنظومة الرئيسية لجمع التعليقات، فحص المحتوى، تصنيف التعليقات، الرد على الأسئلة المعروفة، تحويل الحالات غير المعروفة للمشرفين، وربط الأسئلة الشرعية ببوت الفتاوى الحالي.

## التدفق المعتمد

```text
                    │

             ▼             ▼

             │             │
      إخفاء / مراجعة       ▼

                    تصنيف نوع التعليق
                           │
               ┌───────────┼───────────┐
               ▼           ▼           ▼
          سؤال معروف    غير معروف     فتوى
               │           │           │
           رد تلقائي    المشرفون    بوت الفتاوى
                           │           │
                           ▼           ▼
                          الرد      جواب الشيخ
                                        │

                           ▼            ▼            ▼
                      Telegram فقط   التعليق       الاثنين
                       [الافتراضي]
```

## قواعد أساسية

- لا يقوم الذكاء الاصطناعي بإصدار فتوى.
- الأسئلة المعروفة تستخدم أجوبة معتمدة، ولا يتم اختراع معلومات تشغيلية من النموذج.
- التعليق غير الواضح أو منخفض الثقة يذهب للمراجعة البشرية.
- أي سؤال ديني محتمل يتم توجيهه إلى مسار الفتاوى بدل الرد الآلي.
- كل حدث يجب أن يكون idempotent لمنع تكرار الردود عند إعادة إرسال Webhooks.
- لا تُحفظ Tokens أو Secrets داخل GitHub.

## التقنية المستهدفة

- httpx
